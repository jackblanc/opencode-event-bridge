# Domain Docs

How engineering skills should consume this repo's domain documentation.

## Layout

This is a single-context repo.

- Read `CONTEXT.md` at the repo root before exploring.
- Read relevant ADRs in `docs/adr/`.
- If `CONTEXT-MAP.md` appears later, treat the repo as multi-context and follow that map.

## Vocabulary

Use the terms from `CONTEXT.md` when naming domain concepts in issues, plans, tests, and architecture notes.

## ADRs

If output contradicts an existing ADR, surface the conflict explicitly and explain why reopening the decision is worth considering.
